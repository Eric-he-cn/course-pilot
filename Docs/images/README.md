# 文档截图

由 `scripts/screenshots.py` 生成，UI 改动后重跑一次即可。

- `login.png` — 登录：输入用户名或从随机建议里挑一个；每个用户名对应一份独立的工作区
- `chat-citation.png` — 对话取证：回答带教材文件名与页码，公式正常渲染，底部 SOURCES 可点开原文
- `chat-tools.png` — 工具链可见：自动加载 research、检索教材、联网检索、抓取网页，失败的那一步也显示出来
- `chat-diagram.png` — 图示：mermaid 渲染成 SVG，下方可下载
- `library-notes.png` — 课程笔记：助手整理并存下的学习卡片，可在界面直接查看
- `plan.png` — 学习计划：版本化的每日条目，挂着概念名，历史条目不会被改写
- `archive.png` — 学习档案：按概念的掌握度与证据事件；证据不足时显示「数据不足」而不是编一个百分比
- `help.png` — 使用说明：上手清单按真实状态打勾，能力卡与实例状态都读自接口
- `model-picker.png` — 底部状态栏：随时换模型与思考档位；配几个模型由 .env 决定
- `delete-confirm.png` — 删除前列出连带影响：删一门课会带走它的教材、概念、掌握度、计划与会话
- `context.png` — 上下文构成：输入框旁的占比条，展开后逐段列出字符数

先看判断方式

当一个函数是“函数套函数”时，就要考虑链式法则。教材把它写成复合函数 y=f(u)，u=g(x)，对 x 求导时，需要沿着这条依赖链逐层相乘。

dy/dx = (dy/du) · (du/dx)

例如 sin(x²)：外层是 sin(u)，内层是 u=x²，因此导数是 cos(x²)·2x。一个实用判断是：如果你能圈出“里面那一坨”并把它临时换成 u，通常就需要链式法则。
